# Story 1.1 — RBAC Matrix Lock (context)

**Status:** shipped (commit `fec0834`, 2026-08-21)

**Source:** `_bmad-output/planning-artifacts/epics.md` lines 331–354

## Intent

Epic 1's middleware and every later epic's handler tests must reference
one canonical, machine-readable authority source. This story produces
that source as a Markdown table + a typed TypeScript matrix, plus a CI
lint that fails when a handler references an action not in the matrix.
