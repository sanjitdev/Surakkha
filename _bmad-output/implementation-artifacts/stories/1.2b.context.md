# Story 1.2b — Responsive Layout Shell (context)

**Status:** shipped (commit `822b736`, 2026-08-21)
**Covers:** UX-DR-18
**Source:** `_bmad-output/planning-artifacts/epics.md` lines 380–403

## Intent

Every later epic needs a known canvas to lay out against. This story
renders the sidebar/topbar shell with the documented breakpoint
behaviour (≥1024px desktop, 768–1023px tablet, <768px mobile).

## Acceptance criteria — file mapping

| AC bullet (epics.md) | Satisfaction |
|---|---|
| ≥1024px: 240px dark sidebar (`color.neutral.sidebar #0F172A`) visible on the left | `AppShell.tsx` + `Sidebar.tsx` + `tailwind.config.ts` neutral palette |
| ≥1024px: topbar with brand mark + primary gradient appears at the top | `TopBar.tsx` |
| <1024px: sidebar collapses to a hamburger button in the topbar | `AppShell.tsx` (responsive guard) |
| <1024px: hamburger reveals the same nav items in a drawer | `AppShell.tsx` drawer |
| 768–1023px: horizontal padding 16px | `index.css` breakpoint utilities |
| <768px: padding 12px | `index.css` breakpoint utilities |
